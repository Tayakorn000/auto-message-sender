# Auto Message Sender

โปรแกรมช่วยส่งข้อความ Messenger / คอมเมนต์ / กดไลค์ / แชร์โพสต์ บน Facebook
ผ่าน Chrome หลายโปรไฟล์พร้อมกัน

- `server/` — โปรแกรมหน้าจอ (Python + tkinter) เปิด API ที่ `localhost:5000` ให้ส่วนขยายมาถามงาน
- `extension/` — ส่วนขยาย Chrome (Manifest V3) ที่ลงมือทำงานบนหน้าเว็บจริง

## เริ่มใช้งาน

```bash
pip install flask flask-cors
python server/main.py
```

โหลดส่วนขยาย: `chrome://extensions` > เปิด Developer mode > **Load unpacked** > เลือกโฟลเดอร์ `extension/`
ทำกับ **ทุกโปรไฟล์** ที่จะใช้ แล้วกดไอคอนส่วนขยายเลือก Preset ประจำโปรไฟล์นั้น

ในโปรแกรม: เลือกโหมด > วาง URL > กด **สั่งเปิดหน้าเว็บ** > กดปุ่มสั่งงาน

⚠️ ปิด Chrome ให้หมดก่อนกดปุ่ม "เปิด Chrome Profiles" ไม่งั้นแฟล็กปิดการหน่วง timer จะไม่ถูกใช้

## โหมด

| โหมด | ทำอะไร |
|---|---|
| 💬 Messenger | ส่งข้อความในแชท ติ๊ก "นี่คือลิงก์หน้าเพจ" ถ้าเป็นเพจ (บอทกดปุ่มส่งข้อความ + เริ่มต้นใช้งานให้) |
| 🔴 คอมเมนต์ไลฟ์ | คอมเมนต์ในไลฟ์ |
| 📝 คอมเมนต์โพสต์ | คอมเมนต์โพสต์ล่าสุด + โหมดจับตาดูรูปใหม่อัตโนมัติ |
| 👍 กดไลค์โพสต์ | กดถูกใจ ข้ามโพสต์ที่ไลค์ไว้แล้ว (กดซ้ำ = เอาไลค์ออก) |
| 🔁 แชร์โพสต์ | แชร์ → แชร์ตอนนี้/ไปยังฟีด → กดโพสต์ในกล่องถ้ามี |
| 🔥 ทั้งหมด | ข้อความ + ไลฟ์ + โพสต์ พร้อมกัน |

ไลค์/แชร์ จำกัดขอบเขตอยู่ในตัวโพสต์ (`role="article"` ชั้นนอกสุด) ไม่ไปโดนปุ่มถูกใจของเพจ
ด้านบนหรือของคอมเมนต์ด้านล่าง

⚠️ Facebook จำกัดบัญชีที่ไลค์/แชร์รัวเกินไป ต้องเว้นช่วงเอง โปรแกรมไม่มีตัวหน่วงให้

## อัปเดตอัตโนมัติ

เปิดโปรแกรมแล้วเทียบ `APP_VERSION` กับ tag ของ GitHub Release ล่าสุด (ขอแค่ JSON ก้อนเล็ก
ไม่โหลดไฟล์) เจอตัวใหม่ ส่วนขยายทับให้เลยอัตโนมัติ ส่วน `.exe` ขึ้นปุ่มให้กดในแท็บ **🌐 Setup Chrome** — เน็ตไม่ดีก็เงียบ ไม่มี error เด้ง

ตอนติดตั้ง เขียนไฟล์ใหม่เป็น `.new` ข้าง ๆ แล้วให้ `.bat` รอโปรแกรมปิดก่อนค่อยสลับไฟล์
(Windows เขียนทับ `.exe` ที่รันอยู่ไม่ได้) แล้วเปิดกลับให้เอง — ใช้ได้เฉพาะตอนรันจาก `.exe`

รับเฉพาะไฟล์ `.exe` ที่อยู่บนโดเมน `https://github.com/` เท่านั้น และไฟล์ต่ำกว่า 1MB
ถือว่าโหลดไม่ครบ

**ปล่อยเวอร์ชันใหม่**: แก้ `APP_VERSION` ใน `server/main.py` และ `version` ใน
`extension/manifest.json` ให้ตรงกัน แล้วออก Release ที่ tag ตรงกัน (เช่น `V1.7.0`)
แนบ 2 ไฟล์: `.exe` และ `extension.zip` (ซิปไฟล์ในโฟลเดอร์ `extension/` แบบแบน ไม่ต้องห่อโฟลเดอร์)

```bash
cd extension && zip ../extension.zip background.js content.js manifest.json popup.html popup.js
```

⚠️ แนบไฟล์ผิดแล้วอัปทับ (`gh release upload --clobber`) **ไม่พอ** — CDN ของ GitHub แคชไฟล์เดิม
ไว้ที่ URL นั้นแล้ว (`x-cache: HIT` ETag เดิม) คนโหลดจะยังได้ของเก่า แม้ curl บาง edge จะได้ของใหม่
ต้องลบ release ทิ้งแล้วออก tag ใหม่ให้ URL เปลี่ยน เช็คหลังปล่อยทุกครั้งด้วย
`urllib` (ตัวเดียวกับที่โปรแกรมใช้) ไม่ใช่ `curl`

### ส่วนขยายอัปเดตเองอัตโนมัติ ไม่ต้องกดอะไร

เปิดโปรแกรมแล้วเจอ Release ใหม่ที่แนบ `extension.zip` มา โปรแกรมทับโฟลเดอร์ส่วนขยายให้เลย
ไม่ต้องรอใครกดปุ่ม (หาจาก `extension/` ข้าง ๆ ตัวโปรแกรม หรือ path ที่จำไว้ใน
`autosender_config.json` — หาไม่เจอก็เงียบไว้ ไปถามตอนกดปุ่มอัปเดตแทน ไม่เด้งกวน)
ส่วนขยายเป็นแค่ไฟล์บนดิสก์ ทับได้ทันที Chrome อ่านของใหม่ตอนเปิดครั้งหน้าเอง

ตัวโปรแกรมเองทำแบบนี้ไม่ได้ (Windows แทนที่ `.exe` ที่รันอยู่ไม่ได้) เลยยังต้องกดปุ่ม 1 ที
กดแล้วมันโหลด สลับไฟล์ และเปิดกลับให้เอง — ไม่ต้องไปโหลดจากเว็บเองอีก

**หลายโปรไฟล์ใช้โฟลเดอร์เดียวกัน** — Load unpacked ทุกโปรไฟล์ชี้ไฟล์ชุดเดียวกันบนดิสก์
ทับทีเดียวได้ครบ ปิด Chrome ให้หมดแล้วเปิดใหม่ ทุกโปรไฟล์อ่านไฟล์ชุดใหม่พร้อมกัน
ถ้าเปิดใหม่แล้วโปรแกรมยังขึ้นเตือนว่าเวอร์ชันเก่า กด Reload ที่ `chrome://extensions` ครั้งเดียว
(ยังไม่ได้พิสูจน์อัตโนมัติ — Chrome รุ่นใหม่เลิกรองรับ `--load-extension` แล้ว สั่ง Chrome
ติดตั้งส่วนขยาย unpacked จากสคริปต์ไม่ได้ ตัวโปรแกรมเลยเช็คให้แทนด้วยเวอร์ชันที่ส่วนขยายรายงานกลับมา)

โปรไฟล์ที่ Load unpacked มาจากคนละโฟลเดอร์จะไม่ถูกอัปเดตพร้อมกัน — จับได้จากคำเตือนในแท็บ
Setup Chrome เพราะส่วนขยายส่งเวอร์ชันตัวเองมากับทุก poll (`?v=`) โปรแกรมเลยบอกได้ว่า preset ไหนตกรุ่น

เวอร์ชันส่วนขยายขึ้นที่**หัวหน้าต่าง**ด้วย (`Auto Messenger v1.6.6 | ส่วนขยาย 1.6.6`)
ถ่ายรูปหน้าจอส่งมารูปเดียวก็รู้ว่าเป็นเพราะของเก่าหรือของพัง ไม่ต้องเดา

ส่วนขยายก่อน 1.6.0 ไม่ส่ง `?v=` มาเลย — นับเป็นเวอร์ชันเก่าสุดไว้ก่อน ขึ้นว่า "เก่ามาก ไม่บอกเวอร์ชัน"
(ถ้าปล่อยผ่านเคสนี้ คนที่ยังไม่เคยเอาโฟลเดอร์ใหม่ไปวางเลยจะไม่เห็นคำเตือนอะไรเลย)

ตอนแตกซิปจะไม่ยอมรับ path ที่ออกนอกโฟลเดอร์ (`../`) และซิปที่ไม่มี `manifest.json`

## build เป็น .exe (Windows)

```
pip install pyinstaller flask flask-cors
pyinstaller --onefile --windowed server/main.py
```

## เทส

```bash
python3 server/test_update.py        # ระบบอัปเดต (เซิร์ฟเวอร์จำลอง ไม่แตะเน็ตจริง)
python3 server/test_gui_modes.py     # สลับโหมดแล้ว UI + คำสั่งที่ส่งออกถูก
python3 extension/test_find_input.py # หากล่องพิมพ์เจอโดยไม่ต้องคลิก
python3 extension/test_get_started.py# กดปุ่มเริ่มต้นใช้งานก่อนพิมพ์เสมอ
python3 extension/test_like_share.py # ไลค์/แชร์กดถูกปุ่ม
node    extension/test_background.js # เลือกแท็บก่อนสั่งงาน + routing ตามโหมด
```

เทสฝั่งส่วนขยายดึงฟังก์ชันตัวจริงออกจาก `content.js` / `background.js` มารันใน headless Chrome
กับ DOM จำลอง โดยไม่มีการคลิกของคนเลย
